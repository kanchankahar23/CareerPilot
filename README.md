# CareerPilot - Your AI Career Mentor

CareerPilot is an AI-powered career guidance and recommendation platform that helps users discover the right career path based on their skills, interests, and goals. The platform provides personalized learning roadmaps, job recommendations, and an AI assistant that guides users by answering career-related queries in real time.

The system is designed to help students and job seekers make better career decisions and prepare effectively for placements.

---

##  Features

-  AI Career Assistant for career guidance
-  Personalized Roadmap Generation
-  Job Recommendations based on skills and interests
-  Skill-based Learning Suggestions
-  Secure User Authentication
-  Real-time AI Query Support
-  Career Path Recommendations
-  Responsive and Modern UI
-  Full Stack Web Application

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/kanchankahar23/CareerPilot.git
```

### 2️⃣ Navigate to Project Directory

```bash
cd CareerPilot
```

---

## 🚀 Client Setup

```bash
cd client
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

## 🚀 Server Setup

```bash
cd server
pip install -r requirements.txt
```

Run FastAPI server:

```bash
uvicorn main:app --reload
```

Backend runs on:

```bash
${import.meta.env.VITE_API_URL}
```

---

## 🔥 Environment Variables

Create a `.env` file inside the `server` folder:

```env
GROQ_API_KEY=your_api_key
MONGODB_URL=your_mongodb_url
JWT_SECRET=your_secret_key
```

## 🎯 How It Works

1. User creates an account
2. User enters skills and interests
3. AI analyzes the user profile
4. System generates:
   - Personalized roadmap
   - Career recommendations
   - Job suggestions
   - Learning guidance
5. User interacts with AI assistant for career queries
